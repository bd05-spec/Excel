# Excel Dashboard Projects

This repository collects four Excel workbooks covering aviation, Chicago crime, e-commerce, and electric vehicles. Each workbook is the primary project artifact and is intended to let a reader explore its topic through spreadsheet-based analysis and visual summaries.

## Workbooks

| Project | Area | Workbook |
| --- | --- | --- |
| Aviation Dashboard | Aviation data and operational patterns | [Aviation Dashbaord.xlsx](<Aviation Dashboard/Aviation Dashbaord.xlsx>) |
| Chicago Crime Analysis | Crime data and geographic or categorical patterns in Chicago | [Chicago Crime Analysis (1).xlsx](<Chicago Crime Analysis/Chicago Crime Analysis (1).xlsx>) |
| Ecommerce Dashboard | E-commerce performance and sales analysis | [Ecommerce Dashboard.xlsx](<Ecommerce Dashboard/Ecommerce Dashboard.xlsx>) |
| Electric Vehicle Dashboard | Electric-vehicle population and market patterns | [Electric Vehicle Dashboard.xlsx](<Electric Vehicle Dashboard/Electric Vehicle Dashboard.xlsx>) |

## Open and explore

Download a workbook and open it in Microsoft Excel or a compatible spreadsheet application. Review the workbook's sheets, filters, formulas, and charts to understand its measures and coverage.

## Data and interpretation notes

The repository currently contains the workbooks but no separate project briefs or consistent data dictionary. Dataset provenance, time coverage, refresh steps, and metric definitions should therefore be verified inside each workbook before interpreting or reusing its figures. These are descriptive portfolio analyses, not causal or predictive claims.
